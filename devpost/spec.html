8. Chạy, quay video, đưa lên mạng

npm install
npm run dev          # http://localhost:3000
npm run build        # tạo out/
npx serve out        # xem bản build giống bản online
Vercel: đẩy code lên repo GitHub công khai → vercel.com/new → Import. Vercel tự nhận Next.js, không cần biến môi trường. Mỗi lần push lên main thì Vercel tự build lại.
Hackathon bắt buộc video demo và repo công khai. Vercel là thêm, không thay được hai thứ đó.

9. Chỗ có thể hỏng và cách xử lý

Cần kiểm tra ở bước build đầu tiên: Tailwind 4 qua @tailwindcss/postcss có chạy với Next 16.4 không. Nếu không, chép cấu hình loader của Skill Pack guide.

Nhận xét của Claude

Hành vi nào trong PRD cũng có chỗ trong spec: ngôn ngữ và sáng/tối nằm ở Providers, chi tiết workflow ở WorkflowCard, ảnh ở ScreenshotStrip, Lightbox và script ảnh, link sai ở not-found, thêm dự án ở content/projects và npm run check. Next.js nặng hơn mức một trang portfolio cần. Mình bù lại bằng cách xuất trang tĩnh, không server, không database, chỉ thêm một thư viện là sharp, nên vẫn vừa một POC. Rủi ro thật duy nhất là cấu hình Tailwind 4 với Next 16, và việc này kiểm tra được ngay ở bước đầu. Phần tốn công nhất là viết nội dung song ngữ cho 10 workflow, không phải code.
